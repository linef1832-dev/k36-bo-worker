# K36 บอทหลังบ้าน (Railway) — v0.1

ตอนนี้ทำอย่างเดียว: **ล็อกอินทุกเว็บที่ตั้งบัญชีไว้ในหน้า "บอทหลังบ้าน" ของ K36 แล้วรายงานสถานะกลับ**
(งานแก้ช่องทางชำระเงินจะเพิ่มในเวอร์ชันถัดไป)

## ติดตั้ง
1. สร้าง repo ใหม่ใน GitHub (ตั้งเป็น **Private**) แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้
2. Railway → New Project → Deploy from GitHub repo → เลือก repo นี้
3. แท็บ **Variables** เพิ่ม 3 ตัว:

| ชื่อ | ค่า |
|---|---|
| `SUPABASE_URL` | URL ของ Supabase โปรเจกต์ K36 |
| `SUPABASE_KEY` | คีย์ Supabase ตัวเดียวกับที่ K36 ใช้ |
| `BO_PRIVATE_KEY` | กุญแจลับที่คัดลอกไว้ตอนกด "สร้างกุญแจ" (วางทั้งก้อน รวมบรรทัด BEGIN/END) |

4. Deploy → ดูแท็บ **Logs**

## Logs ที่ควรเห็น
```
🔑 ลายนิ้วมือกุญแจ: XXXX-XXXX-XXXX-XXXX   ← ต้องตรงกับในหน้า K36
🌍 IP ขาออกของบอท: x.x.x.x
✅ bt678 ล็อกอินสำเร็จ
```
และการ์ดใน K36 จะเปลี่ยนเป็น **"ล็อกอินได้"** ภายใน 1 นาที

## กันพัง
- ล็อกอินพลาด → รอ 15 นาทีก่อนลองรหัสเดิมซ้ำ (กันบัญชีโดนล็อก) เปลี่ยนรหัสใน K36 แล้วลองใหม่ทันที
- ล็อกอินใหม่เองก่อน token หมดอายุ 20 นาที
- ไม่บันทึกรหัสผ่านหรือ token ลง log หรือฐานข้อมูล
- ห้ามใส่รหัสผ่าน / กุญแจลับ ในไฟล์ใน GitHub — ใส่ใน Railway Variables เท่านั้น
